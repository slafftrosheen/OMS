# Canvas tool audit — 24 November 2026

This audit exercised OMS canvas tools after the physical-scale update in
`b3a503e04f345194cbfbf7d3a988cdf8f91ae866`. It used synthetic documents, the
installed native editor/store/history, mounted React controls, actual export
pipelines, and isolated PostgreSQL/WASM databases. No live orders were changed.

## Reproduced product defects and corrections

| Area | Reproduced failure | Correction and regression coverage |
| --- | --- | --- |
| Guide dragging | Physical Q did not bypass snapping on a Russian keyboard because its text was `й`. | Press and release recognize `KeyQ`; lowercase, uppercase, and Cyrillic cases release and reacquire snapping without moving the pointer. |
| Rotation handles | The rotation preview rejected its own active pointer claim, making every drag invalid. | A dedicated preview path requires the rotation owner and idle native selection state. Numeric commands retain their busy guard; commit still checks the revision after releasing the pointer. All four handles, modifiers, nested transforms, and undo/redo are covered. |
| Copied dimensions | Duplicated associative dimensions continued referring to the original source objects. | Internal references are remapped before copied records enter the store. Tests cover root and nested-group copies, external references, Alt-copy/cancellation, clipboard content placement, grid repetition, undo, and redo. |
| Bézier handles | The final mouse-release coordinate was ignored, leaving handles at the last move event. | Genuine drags consume the exact release point. Raw press coordinates distinguish real movement from snapping displacement, so stationary snapped clicks remain corners. Shift, read-only cancellation, and one-step undo/redo are covered. |
| Circle bounds | A circle centered at X=999900 with radius 300 passed validation despite reaching X=1000200. | Both opposite corners and final native bounds must fit the ±1000000 coordinate envelope. Invalid endpoints clear the preview and cannot commit a stale shape. |
| Circle refusal | Refused or rewritten native writes could leave an active or stale preview. | Creation/update verifies page, transform, requested geometry, outline metadata, and final bounds; failure cancels and restores earlier artwork. |
| Rotated pocket drops | The enclosing page rectangle captured drops outside the rotated pocket body. | Hit testing uses the actual local rectangle. |
| Clipped pocket drops | A nested pocket captured drops in areas hidden by its parent's clipping. | Hit testing respects the native ancestor mask. |
| Rotated attachment placement | Moving a viewer between differently rotated pockets could overlap the header or clip the card. | Layout packs rotated extents while retaining orientation, including row spacing, complete bounds, and stable repeated arrangement. |
| Narrow pocket layout | Rotated generated cards could overlap or be cropped in a narrow pocket. | The frame grows only enough for a minimum readable card, while preserving transactional refusal/rollback behavior. |
| Hidden export bounds | Invisible native shapes or descendants of invisible groups enlarged SVG/PNG output, sometimes exceeding the PNG size budget. | Native artwork now receives the same ancestor-opacity filtering as CAD artwork before export bounds are calculated. |

## Test infrastructure and fixture corrections

The lightweight runner left every bundled test module in `/tmp/rf-vitest`.
The broad run exhausted a 4.9 GB temporary filesystem. Each run now uses its own
temporary directory and removes it after completion or an import failure. A
fatal import still exits after cleanup even if the partially imported module
left a timer running. Regression coverage also verifies that another run's
directory is preserved.

Several existing assertions exposed obsolete fixtures rather than product
failures. Node-selection fixtures now model native immutable records and exact
rollback identity; the equivalent real-editor operations pass. The cubic
construction test now supplies real CAD shape utilities and bounds. Two draft
form markup hashes were reviewed against their feature commits and updated for
the authorized named-station-element and pocket-selector recovery changes.
The strict form locks remain, with additional section/control invariants.

## Repeat the local suite

From the repository root, with dependencies installed:

```sh
npm run test:canvas
```

This command discovers the CAD, drawing, and canvas unit/editor tests plus the
related physical layout, material, form, and runner checks. It runs small
sequential batches to bound memory, prints full diagnostics for failed batches,
then executes the canvas file-pocket/export database contracts and the media
migration checks in isolated PGlite databases. It does not connect to production.

Browser scenarios remain a separate command:

```sh
npx playwright test --config tests/ui/playwright.drawing-workspace.config.ts
npx playwright test --config tests/ui/playwright.cad-files.config.ts
npx playwright test --config tests/ui/playwright.order-canvas.config.ts
```

For the independent DXF reader:

```sh
NODE_ENV=test node --import tsx scripts/qa/export-cad-fixture.ts /tmp/oms-canvas-reference.dxf
python3 scripts/qa/verify-cad-fixture.py /tmp/oms-canvas-reference.dxf
```

The Python check uses the separately installed QA dependency `ezdxf`.
`NODE_ENV=test` prevents editor development channels from keeping the export
script alive after the file is written.

## Independent review and remaining limits

A separate reviewer inspected the source changes and the relevant installed
tldraw implementations. The review found two issues in the initial fixes:
stationary snapped Bézier clicks creating handles, and fatal test imports
remaining alive after cleanup. Both were corrected and independently rechecked.
No further concrete blocker remained in that bounded review.

The dimension-copy adapter follows the installed tldraw 2.4.6 batch ordering.
Keep its duplication, Alt-copy, group, paste, and repeated-grid regressions in
the required checks when upgrading tldraw.

Chromium could not start in this environment. Its process terminated before
opening a page with `socket() failed: Operation not permitted (1)`. Therefore
this audit does **not** establish actual browser layout, overflow, native font
wrapping, visual appearance, hardware pen behavior, or operating-system
clipboard integration. Text tests use deterministic metrics; clipboard tests
exercise the real native content-placement API. Local database tests do not
verify a live Supabase deployment. No production deployment or real CAD/CAM
machine trial was performed.
