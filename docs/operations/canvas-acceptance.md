# Приёмочные тесты Canvas и создания заказов

Это последовательность проверки кандидата перед рабочими заказами. Автоматические проверки геометрии не заменяют открытие DXF в вашей CAD/CAM и пробу на станке. Используйте отдельный заказ и доску с названием `QA-CAD / TEST ONLY`.

## Подготовка

Запишите `git rev-parse HEAD`, браузер, ОС, роль, язык и дату проверки. После обновления OMS примените обычную процедуру сборки приложения; эта серия изменений не требует миграции БД. Проверьте, что браузер загрузил обновлённую версию.

Контрольный файл: [production-reference.dxf](../../tests/fixtures/cad/production-reference.dxf). Он создан из синтетической геометрии, без данных клиентов. Скачать исходный файл можно через GitHub → Raw → Save.

| Объект | Ожидаемая геометрия в мм |
|---|---|
| Панель | Замкнутый прямоугольник 1200 × 600; нижний левый угол (0, 0) |
| Круг | Центр (100, 100), радиус 25 |
| Эллипс | Центр (600, 300), вектор большой полуоси (100, 100), отношение полуосей 0,5 |
| Дуга | Центр (1050, 150), радиус 100, от 350° до 80° против часовой стрелки |
| Открытая линия | От (−20, 0) до (−20, 600) |
| Замкнутая кривая | Два кубических сегмента, 7 контрольных точек в DXF SPLINE |
| Открытая кривая | Один кубический сегмент, 4 контрольные точки в DXF SPLINE |

Всего: **7 объектов, 4 замкнутых и 3 открытых контура**. Общие габариты **1220 × 600 мм**: линия находится на 20 мм левее панели. Не перепутайте общие габариты с размером самой панели.

## Основной маршрут — повторить на доске идей и в заказе

| Шаг | Действие | Критерий прохождения |
|---|---|---|
| 1 | Layout → Document: mm, масштаб 1:10, применить. File → DXF: импортировать контрольный файл, сохранить исходные координаты | Предпросмотр 1220 × 600 мм, единица mm, пропусков нет |
| 2 | Применить импорт, выделить панель; изменить zoom, затем единицы отображения на inches | Физический размер панели остаётся 1200 × 600 мм; zoom не меняет геометрию |
| 3 | Экспортировать только импортированные объекты в режиме SPLINE | 7 сущностей, 4 закрытых/3 открытых; файл объявляет миллиметры |
| 4 | Открыть DXF в рабочей CAD/CAM | Размеры, положение, дуга, кривые и число контуров совпадают с таблицей; отсутствуют лишние линии |
| 5 | Сохранить доску/черновик, выйти, открыть повторно | Геометрия, единицы и масштаб сохранены; форма заказа и вложения доступны |
| 6 | В новой форме переключить «Форма → Чертёж → раздел формы → Чертёж» | Поля, кривые и выбранный масштаб сохранены |
| 7 | F10: разорвать замкнутую кривую в узле, затем замкнуть | Геометрия прежняя, на шве нет дополнительного нулевого сегмента; Undo возвращает открытый контур |
| 8 | Разорвать открытую кривую в промежуточном узле; Join → ближайшие концы → предпросмотр → применить | Зазор 0 мм; исходные сегменты восстановлены; Undo возвращает две части |
| 9 | Для разнесённых концов сравнить прямое соединение и слияние с допуском | Прямое соединение сохраняет исходные сегменты; слияние выше допуска отказано, внутри допуска сдвигает концы в середину зазора |
| 10 | Изменить объект после предпросмотра Join/Offset/Import или DXF export | Применение/скачивание заблокировано до повторного предпросмотра |

## Инструменты для реальных макетов

- **Текст:** создать `BŪVE / РЕКЛАМА / B8O`, преобразовать в кривые. Проверить внутренние отверстия, размеры, расположение и шрифт. После сохранения/перезагрузки экспорт не должен требовать исходный шрифт. Для выбранного текста сравнить переносы и интервалы до замены оригинала.
- **Узлы:** выбрать сегмент, переключить прямая/Безье, изменить ручки, разделить сегмент, удалить узел. Проверить Undo/Redo и соседние сегменты. Превращение в прямую намеренно меняет выбранный сегмент.
- **Combine / Break apart:** объединить панель и вложенный круг. При offset отверстие должно сохраняться. Break apart превращает внутренний контур в самостоятельный объект; последующий Weld отдельных объектов объединяет их как сплошные области.
- **Weld / Trim / Intersect:** два квадрата 100 × 100 мм со смещением 50 мм по X. Площади результатов: 15000 / 5000 / 5000 мм². Для Trim явно выбрать цель. Сначала работать с сохранением оригиналов и разнести результат перед экспортом, чтобы не оставить двойные траектории.
- **Offset:** квадрат 100 × 100 мм, miter, +2 мм → 104 × 104 мм; −2 мм → 96 × 96 мм. Затем проверить настоящий знак с отверстиями. Малые элементы при отрицательном offset могут исчезнуть — проверять предпросмотр.
- **Полилинейный DXF:** экспортировать кривые с допуском 0,01 мм. Сравнить с SPLINE в рабочей CAD/CAM. Результат аппроксимирован; исходные кривые OMS не меняются.
- **Импорт:** отдельно проверить свой DXF из Corel, unitless DXF и файл с TEXT/HATCH. Без известных единиц нужен ручной выбор. Пропуски видны и требуют подтверждения. CDR/DWG сначала экспортировать в DXF вне OMS.

## Сохранение и ошибки

1. Изменить поля, профиль, количество, добавить файл и кривую. Попытаться уйти через навигацию, затем обновить вкладку. Отмена предупреждения сохраняет всё на месте. Изменение одного лишь раскрытия профиля не вызывает предупреждения.
2. Начать полилинию/Безье с несколькими точками и нажать сохранение. После открытия заказа завершённый контур остаётся в чертеже; одиночный незавершённый узел не считается готовой кривой.
3. В DevTools замедлить сеть. Начать сохранение. Профили, количество и остальные поля недоступны для изменения до завершения. Повторный клик не создаёт второй заказ.
4. Загрузить два тестовых файла; один запрос загрузки прервать. Показана ошибка, успешный файл помечен как прикреплённый. Повтор сохраняет тот же черновик и не загружает успешный файл заново.
5. После частичной загрузки удалить успешно прикреплённый файл. Отмена подтверждения ничего не удаляет. При ошибке DELETE файл остаётся в списке. При успехе он исчезает и из сохранённого заказа; повторная загрузка/сохранение во время DELETE недоступны.
6. Удалить вложение, пока чертёж скрыт. Сохранить и открыть заказ: отсутствует удалённый viewer и его привязки, другие объекты и вложения сохранены.
7. Ввести количество 0 или 101, сохранить из вида чертежа. Откроется форма, количество помечено ошибкой и получает фокус. Исправление и повтор позволяют сохранить.
8. Открыть один заказ в двух вкладках, изменить и сохранить в первой. Сохранение устаревшей второй вкладки должно показать конфликт, а не перезаписать первую.
9. Под обычной ролью открыть подтверждённый заказ. Чтение/просмотр доступны согласно роли, изменение формы и CAD запрещено. Проверить отдельно заблокированный объект и объект внутри заблокированной группы.

## PDF и OpenRouter

В тестовом черновике открыть помощник и загрузить небольшой PDF с явными материалами, размером, датой и адресом. Сначала проверить результат анализа, затем применить только выбранные поля. Неуверенные варианты и несопоставленные материалы должны остаться на проверку оператора. Переключение языка EN/RU/LV должно отражаться в интерфейсе и ответе помощника.

Повторить с PDF-сканом. Проверить выбранный режим обработки и доступность модели в R&D. Платный OCR не должен включаться автоматически. При 429/503 поля и вложения остаются на месте; нет ложного сообщения об успешном анализе или бесконечных повторов.

Если остаётся 503, записать статус и безопасный `code` ответа запроса анализа, время, режим PDF и выбранную модель. Различать отказ провайдера, недоступные настройки, метаданные файла и хранилище. API-ключи и содержимое рабочих PDF в отчёт не включать. Успешность живого OpenRouter здесь пока не подтверждена.

## UI и автоматические проверки

Проверить EN/RU/LV, светлую/тёмную тему, desktop 1440 px и узкое окно 390 px, клавиатуру Tab/Enter/Escape и масштаб браузера 200%. При длинном имени файла кнопки удаления/просмотра должны оставаться доступны. В браузерах с зарезервированными Ctrl+L/K использовать меню Object.

Из корня репозитория:

```sh
npm ci
npm test
npm run test:unit
npm run check
npm run build
npx playwright install chromium
npx playwright test --config tests/ui/playwright.drawing-workspace.config.ts
npx playwright test --config tests/ui/playwright.production-intake.config.ts
# Независимый DXF-reader, отдельная QA-зависимость:
python -m pip install ezdxf==1.4.4
python scripts/qa/verify-cad-fixture.py tests/fixtures/cad/production-reference.dxf
```

`check` и `build` выполнять последовательно. Браузерные тесты используют синтетические данные и перехваченные API-запросы; они не заменяют проверку живых Supabase, OpenRouter и CAD/CAM. В размещённой среде Chromium пока завершается до загрузки страницы (`socket() Operation not permitted`). Сценарии подготовлены, но их прохождение здесь не заявляется.

## Решение о переходе на рабочие заказы

Блокирующие дефекты: потеря данных, неверные размеры/единицы, пропавшие отверстия, лишние траектории, обход блокировки/роли, перезапись чужой версии. Для каждого сбоя записать шаг, ожидаемый и фактический результат, версию OMS и приложить синтетический пример либо разрешённый рабочий файл.

До отказа от Corel проверить минимум один простой заказ, один текстовый знак с отверстиями и один сложный импортированный макет в вашей реальной CAD/CAM. Машинную пробу делать после проверки геометрии и настройки станка оператором. Нативный CDR/DWG, произвольные NURBS, полный обмен слоями/листами, произвольные скругления кривых/вогнутых контуров, текст по контуру, ассоциативные размеры и CAM пока не реализованы.


Трассировка, PDF/EPS, рациональные сплайны DXF, заливка/обводка и скругление выпуклых многоугольников описаны в [Canvas vector exchange](canvas-vector-exchange.md). Проверяйте таблицу ограничений форматов перед приёмкой.
